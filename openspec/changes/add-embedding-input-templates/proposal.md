## Why

Several widely used local embedding models (EmbeddingGemma, Nomic Embed Text, E5, BGE) are trained with a task prefix on every input, and the prefix for a search query differs from the one for an indexed document. The server sends both kinds of text bare, so these models run below the retrieval quality they were trained for. In a test on 241 chunks from 16 documentation pages with 12 questions, EmbeddingGemma 2 ranked the right page first for 9 questions without prefixes and for all 12 with them.

A proxy in front of the embedding endpoint cannot fix this reliably: a query and a chunk arrive as the same kind of request, and only the server knows which one it is sending.

## What Changes

- Add two settings, `embeddings.queryTemplate` and `embeddings.documentTemplate`. Each is a template in which `{text}` stands for the text to embed. Both default to empty, which sends the text unchanged, so existing installations behave as before.
- Apply the query template to each search query before it is embedded, and the document template to each chunk (metadata header included) before it is embedded.
- Reject a non-empty template without the `{text}` placeholder when the configuration is loaded.
- A template rather than a plain prefix, because environment values are trimmed: a prefix ending in a space (`query: `) would lose it, while `query: {text}` cannot.
- Detect config files generated by earlier releases by the embedding settings that existed then, so that adding settings to `embeddings` does not turn their generated default `vectorDimension` into an explicit one.

Out of scope: detecting a changed document template the way a changed model is detected. A changed template leaves stored vectors comparable but embedded inconsistently; the documentation tells operators to re-index. Model-specific defaults are also out of scope.

## Capabilities

### New Capabilities

_None._

### Modified Capabilities

- `embedding-generation`: adds a requirement for embedding input templates.

## Impact

- Affected code: `src/utils/config.ts` (settings, validation, legacy config detection), `src/store/DocumentStore.ts` (the two embedding call sites), new `src/store/embeddings/EmbeddingTemplate.ts`.
- Affected tests: `src/store/embeddings/EmbeddingTemplate.test.ts`, `src/store/DocumentStore.test.ts`, `src/utils/config.test.ts`.
- Affected docs: `docs/guides/embedding-models.md` (new "Task Prefixes" section), `docs/setup/configuration.md`.
- No dependency changes. No change to CLI flags, MCP tools or the database schema.
